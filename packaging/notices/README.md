# Supplemental upstream notices

License texts and attribution records from the exact upstream PySide/Qt source
archives in `sources.json` are retained verbatim here because wheel metadata does
not include the full open-source license texts. Only text notices are copied;
no example media, plug-ins or third-party binaries are included.

The Qt records cover the source modules conservatively; not every optional
component is enabled in the installed Qt binaries. These notices supplement the
installed wheel notices collected at build time. They do not supply complete
corresponding source or certify the final platform dependency inventory.

When changing the locked Qt version, refresh these notices and their archive
checksums. See `docs/RELEASE_CONTENTS.md` and `packaging/release_review.json` for
the remaining publication checks.
